# 💬 Message Explorer для Google Colab

Один файл с кодом, который превращает CSV-выгрузку сообщений (чат, канал, переписка) в красивый интерактивный анализ: активность во времени, рекорды, авторы, частые слова и облако слов, хэштеги и ссылки, автоматические темы, настроение сообщений, поиск и HTML-отчёт.

По умолчанию код анализирует файл `/content/Messages_МосУ_МВД_России_имени_В_Я_Кикотя.csv`, но подойдёт для любой похожей выгрузки.

## 🚀 Как запустить

1. Загрузите CSV-файл в Google Colab (панель «Файлы» слева → папка `/content`).
2. Скопируйте всё содержимое файла [`messages_explorer.py`](messages_explorer.py) в одну ячейку.
3. Если файл называется иначе, поменяйте переменную `FILE_PATH` в начале кода.
4. Нажмите **Shift + Enter**.

Всё нужное (pandas, matplotlib, seaborn, scikit-learn, wordcloud, ipywidgets) в Colab уже установлено.

## 🧭 Автоматическая настройка под файл

Код сам разбирается со структурой CSV:

- **Кодировка**: UTF-8, UTF-8 с BOM или Windows-1251.
- **Разделитель**: запятая, точка с запятой, табуляция или `|`.
- **Колонка с текстом**: ищется по названию (`text`, `message`, `сообщение`, `текст`…), иначе берётся колонка с самыми длинными строками.
- **Колонка с датой**: ищется по названию (`date`, `time`, `дата`…) или по содержимому. Понимает ISO-формат, `дд.мм.гггг чч:мм` и Unix-время.
- **Колонка с автором**: `from`, `author`, `sender`, `автор`, `отправитель`…
- **Метрики**: просмотры, лайки, реакции, репосты, комментарии.

Если что-то определилось неверно, укажите колонки вручную в начале кода:

```python
TEXT_COL = "text"
DATE_COL = "date"
AUTHOR_COL = "from"
```

Разделы, для которых в файле нет данных (например, авторов или дат), просто пропускаются.

## 🧰 Команды после запуска

```python
search("экзамен")                          # поиск с подсветкой и графиком упоминаний
search("экзамен", author="Имя")            # поиск только у одного автора
word_trend("экзамен, сессия", freq="M")    # тренд слов: D — дни, W — недели, M — месяцы
author_card("Имя")                         # профиль автора: активность, любимые слова и час
random_message()                           # случайное сообщение
export_excel("экзамен")                    # выгрузить найденные сообщения в Excel
make_report()                              # скачать HTML-отчёт со всеми графиками
M                                          # таблица сообщений (pandas DataFrame)
RAW                                        # исходный файл как есть
```

## 🧠 Как устроен код

- **Загрузка.** `read_csv_smart` перебирает кодировки и с помощью `csv.Sniffer` определяет разделитель. Если файл прочитался в одну колонку, пробует другие разделители.
- **Определение колонок.** `detect_date`, `detect_text` и `detect_author` ищут колонки по ключевым словам в названии, а если не находят, то по содержимому: доле распознанных дат, длине строк и числу уникальных значений.
- **Таблица `M`.** Это единая таблица сообщений с колонками `text`, `date`, `author`, длиной, числом слов, списком слов (`tokens`) и оценкой настроения. Сообщения без текста отбрасываются.
- **Слова.** Текст приводится к нижнему регистру, `ё` заменяется на `е`, ссылки вырезаются. Затем отбрасываются короткие слова и около 200 служебных слов (русских и английских).
- **Темы.** Тексты превращаются в TF-IDF-векторы, а NMF раскладывает их на 2–6 тем в зависимости от объёма данных.
- **Настроение.** Используется простой словарь примерно из 60 корней: позитивных («спасиб», «поздрав», «успех»…) и негативных («проблем», «отмен», «жаль»…). Это грубая оценка общей тенденции, а не точный анализ смысла.
- **Отчёт.** Каждый график сохраняется функцией `show()` в формате PNG (base64), а `make_report()` собирает все графики в один автономный HTML-файл.
- **Интерактив.** Вкладки построены на `ipywidgets.Tab`. Без виджетов те же возможности доступны через функции.
